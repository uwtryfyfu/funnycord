# Changelog

## 0.1.2
- LICENSE files (LICENSE, LICENSE.txt, LICENSE.md, LICENCE, COPYING) now get their own icon instead of the generic file icon
- Funny mode has license-specific quips ("Reading the fine print in LICENSE")
- Project is now published under the MIT License

## 0.1.1
- Hidden file and folder patterns: exclude specific files/folders from being shown in your Discord status
- New settings added to configure hidden patterns via the manage menu or settings UI

## 0.1.0
- Initial release: Discord Rich Presence with custom per-language icon keys, idle detection, and configurable file/workspace visibility
- Git branch name shown in the state line (auto-detected via the built-in git extension)
- Up to two clickable buttons: auto-detected "View Repository" (from git remote) + one optional custom button
- "Funny mode": playful per-language status text ("Wrestling with app.js") and idle quips, on by default - toggle off via `discordRpc.funnyMode`
